# AI 통합

overlay-kit은 AI 에이전트가 라이브러리에 실제로 존재하는 API를 근거로 답하도록 — 상상한 API가 아니라 — 몇 가지 일반 텍스트 엔드포인트를 제공합니다. ChatGPT, Claude, Cursor 같은 도구는 이 엔드포인트를 읽고 라이브러리에 대한 질문에 정확하게 답할 수 있습니다.

엔드포인트는 [llms.txt](https://llmstxt.org) 컨벤션을 따릅니다. 어시스턴트나 사람이 별도 도구 없이 채팅창에 그대로 붙여 넣을 수 있는 Markdown 파일입니다. URL이 고정이라 북마크, 커스텀 인스트럭션, 지식 베이스에 그대로 등록해 둘 수 있습니다.

## 엔드포인트

| URL | 내용 |
|---|---|
| [`/llms.txt`](https://overlay-kit.slash.page/llms.txt) | 모든 가이드와 API 페이지가 한 줄 설명과 함께 링크된 Markdown 인덱스. 어시스턴트에게 문서 구조를 먼저 알려주고 페이지를 그때그때 가져오게 할 때 사용합니다. |
| [`/llms-full.txt`](https://overlay-kit.slash.page/llms-full.txt) | 영문 문서 전체를 하나의 Markdown 파일로 합친 것. 문서 전체를 한 번에 대화창, 벡터 스토어, prompt cache에 넣고 싶을 때 사용합니다. |
| [`/ai.txt`](https://overlay-kit.slash.page/ai.txt) | 공식 API 표면에 대한 짧고 신뢰도 높은 사실 모음. 어시스턴트가 존재하지 않는 메서드를 만들어내지 않도록 잡아 줍니다. |

세 엔드포인트는 영문만 제공됩니다. 한국어를 포함한 개별 페이지의 Markdown은 아래의 **마크다운 복사** 버튼으로 가져올 수 있습니다.

## ChatGPT

문서 페이지 우측 상단의 **마크다운 복사** 버튼에서 **ChatGPT에서 열기**를 선택하세요. ChatGPT가 다음 prompt가 미리 입력된 상태로 열립니다:

```
Read <page-url>, I want to ask questions about it.
```

라이브러리 전반에 대해 묻고 싶다면 전체 문서 URL을 직접 붙여 넣으세요:

```
Read https://overlay-kit.slash.page/llms-full.txt, I want to ask questions about it.
```

## Claude

같은 드롭다운의 **Claude에서 열기**는 [claude.ai](https://claude.ai)에서 동일한 prompt로 열립니다. `/llms-full.txt`를 직접 붙여 넣어도 똑같이 동작합니다.

## 페이지 자체 복사하기

ChatGPT나 Claude가 아닌 다른 도구 — 로컬 모델, 에디터 AI, 슬랙으로 전달하고 싶을 때 — **마크다운 복사** 버튼의 **왼쪽**을 클릭하세요. 현재 페이지의 원본 MDX를 그대로 가져와 클립보드에 복사하므로 어디든 붙여 넣을 수 있습니다.

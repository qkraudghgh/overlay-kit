# LLMs.txt

overlay-kit's documentation is designed to be friendly to large language models. You can hand the docs to an LLM-powered assistant (ChatGPT, Claude, Cursor, etc.) and have it answer questions or generate code that actually compiles against this library.

To make that easy, the site exposes three text endpoints alongside the regular HTML pages.

## Endpoints

| URL | What it is | When to use |
|---|---|---|
| [`/llms.txt`](https://overlay-kit.slash.page/llms.txt) | A short Markdown index of the documentation — every guide and API page listed as a link with a one-line description. | When you want the assistant to know the shape of the docs and pull in specific pages on demand. |
| [`/llms-full.txt`](https://overlay-kit.slash.page/llms-full.txt) | The full English documentation concatenated into a single Markdown file. MDX-only wrappers are stripped; prose, code blocks, and tables are preserved. | When you want to drop the entire docs into a single conversation, vector store, or prompt cache. |
| [`/ai.txt`](https://overlay-kit.slash.page/ai.txt) | High-confidence facts about overlay-kit and a "do not hallucinate" guardrail listing the exact API surface. | When you want to keep the assistant from inventing APIs that do not exist. |

These three files follow the spirit of the [llms.txt](https://llmstxt.org) proposal. They are plain text and do not require any tooling to consume.

## Working with assistants

### Copy Markdown chip

Every page under `/docs` and `/api` has a **Copy Markdown** chip in the top-right.

- Click the label to copy the page's raw MDX to your clipboard, ready to paste into any assistant.
- Click the caret to open the current page pre-filled in ChatGPT or Claude. The prompt is:

```
Read <page-url>, I want to ask questions about it.
```

You can also paste a one-liner manually for the whole docs:

```
Read https://overlay-kit.slash.page/llms-full.txt, I want to ask questions about it.
```

The assistant will fetch the page and answer follow-up questions grounded in the docs.

### Cursor / VS Code (editor)

You can paste any of the URLs above as documentation context in your editor's AI assistant. A first-party MCP server for overlay-kit is not provided yet — that may come later.
